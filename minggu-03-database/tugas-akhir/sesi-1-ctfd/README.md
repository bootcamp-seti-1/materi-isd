# Sesi 1 — Kuis CTFd Database (60 menit)

10 soal, jawaban berupa teks pendek yang dikirim ke CTFd. Tiap soal punya foldernya sendiri berisi `SOAL.md` dan berkas pendukung.

## Cara mengerjakan

1. Buka terminal Ubuntu, lalu: `sudo service mysql start`
2. Buka folder soal, mis. `cd ~/seti-isd-materi/minggu-03-database/tugas-akhir/sesi-1-ctfd/soal-01`
3. Baca `SOAL.md` di VS Code. Ikuti langkah awalnya (menjalankan `data.sql`).
4. Kirim jawaban ke CTFd, sesuai "Cara menjawab" di soal tersebut.

Ganti `p00` di perintah dengan ID-mu (huruf kecil). Password MySQL: `sakura123`.
