# SETI-P — Industrial Software Development: Materi Peserta

Materi hands-on bootcamp, 12 minggu. Semua lembar ditulis dalam Markdown supaya bisa dibuka langsung di GitHub dan kodenya disalin dengan tombol copy.

## Cara memakai

1. Buka folder minggu yang sedang berjalan.
2. Buka lembar hari yang dikerjakan, misalnya `hari-1-hands-on.md`.
3. Ikuti langkahnya berurutan. Ketik hanya isi kotak **Ketik**, sisanya dibaca.
4. Tertinggal? Pakai **Jalur kejar** di bagian bawah lembar.
5. Stuck? Tulis di grup: ID, bagian, dan pesan error. Contoh: "P08 stuck di E1".
