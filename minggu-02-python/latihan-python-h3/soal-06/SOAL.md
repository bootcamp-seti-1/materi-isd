# Soal 6 — Modul yang Tidak Ditemukan

**Tingkat:** Easy · **Poin:** 100
**Folder:** `~/latihan-python-h3/soal-06`

**Cerita.** Rina memindahkan `sakura-tasks` ke Ubuntu dan programnya langsung
bermasalah: Python bilang modulnya tidak ketemu. Padahal dia yakin filenya ada di folder
yang sama. Setelah itu dia sempat membetulkan satu hal, dan error yang lain muncul.
Mas Bayu bilang, "Bacalah pesan errornya baik-baik. Pesannya jujur, kok."

**Bahan.** Folder ini berisi `Tugas.py` dan `main.py`. Jalankan `uv run main.py` dan baca
pesan error pertama. Betulkan, jalankan lagi, dan baca pesan error berikutnya. Teruskan
sampai programnya berjalan dan mencetak daftar tugas.

**Pertanyaan.** Sebutkan nama dua error yang muncul, berurutan: yang pertama kamu temui,
lalu yang kedua.

**Cara menjawab.** Tulis nama kedua error dengan **huruf kecil semua**, berurutan, dipisah koma tanpa spasi. Contoh bentuknya: `syntaxerror,typeerror`. Kirim jawabannya ke CTFd.
