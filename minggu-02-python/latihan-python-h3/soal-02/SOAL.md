# Soal 2 — Kode yang Tidak Mau Jalan

**Tingkat:** Easy · **Poin:** 100
**Folder:** `~/latihan-python-h3/soal-02`

**Cerita.** Dimas, anak magang, mengetik fungsi-fungsi `sakura-tasks` dari ingatan.
Hasilnya tidak mau jalan sama sekali. Setiap kali dijalankan, Python langsung
mengeluh. Mas Bayu menyerahkan file itu kepadamu: "Tolong betulkan, jangan ubah isi
programnya, cukup perbaiki yang salah penulisannya."

**Bahan.** File `main.py` di folder ini. Jalankan dengan `uv run main.py`. Ada lebih dari
satu kesalahan. Betulkan satu per satu sampai program berjalan sampai selesai.

**Pertanyaan.** Setelah diperbaiki, baris terakhir yang tercetak berbentuk
`Total … | selesai … | belum …`. Berapa angka ketiganya?

**Cara menjawab.** Tulis tiga angka itu berurutan (total, selesai, belum), dipisah koma tanpa spasi. Contoh bentuknya: `5,2,3`. Kirim jawabannya ke CTFd.
